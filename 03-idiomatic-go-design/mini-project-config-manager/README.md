# Mini-Project: Reusable Configuration Manager

A clean, idiomatic Go library for loading, defaulting, and validating application configurations from environment variables.

## Key Features
- **Zero External Dependencies**: Implemented purely using the Go standard library.
- **Sensible Defaults**: Provides safe fallback values for missing environment keys.
- **Structured Error Handling**: Returns typed validation errors specifying offending fields.
- **Comprehensive Unit Testing**: Includes 100% table-driven unit tests.

## Running the Tests
```bash
go test -v ./03-idiomatic-go-design/mini-project-config-manager/...
```
